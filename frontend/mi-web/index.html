wellness-ops

Live in production

Full-stack app on
Kubernetes

A wellness journal deployed across three environments (dev / staging / prod) on a self-hosted kubeadm cluster running on Proxmox. Full GitOps with ArgoCD, observability stack, and automated CI/CD pipelines.

kubeadm ArgoCD SealedSecrets Prometheus Grafana Loki Velero Cloudflare Tunnel GitHub Actions Terraform AWS
↗ Source code ↗ Portfolio ↗ LinkedIn
  • 3-node kubeadm cluster on Proxmox VE homelab (Ryzen 5, 48GB RAM)
  • GitOps — every change tracked in git, ArgoCD syncs automatically
  • 3 environments — dev · staging · prod with NodeAffinity per worker
  • Observability — 6 Grafana dashboards, Alertmanager + Gmail SMTP
  • CI/CD — GitHub Actions + ARC self-hosted runner, GHCR images
  • Security — SealedSecrets, NetworkPolicies, non-root containers
  • Backups — Velero + S3 weekly snapshots (eu-west-1)
  • Exposed via Cloudflare Tunnel — zero open ports
